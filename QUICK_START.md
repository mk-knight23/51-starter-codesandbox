# 🧪 Vue 3 Playground - Quick Start Guide

## What is This?

An **interactive Vue 3 learning playground** with 4 hands-on tutorials. Perfect for beginners, tutorials, and workshops.

---

## 🚀 Quick Start (3 Ways)

### 1. CodeSandbox (Easiest)
```
1. Go to codesandbox.io
2. Import this GitHub repo
3. Start learning instantly!
```

### 2. Local Development
```bash
cd "/Users/mkazi/60 Projects/51-starter-codesandbox"
npm install
npm run dev
```

### 3. Production Build
```bash
npm run build
npm run preview
```

---

## 📚 Learning Path (4 Steps)

### Step 1: Reactive State
**File**: `src/components/playground/CounterDemo.vue`
**Learn**: `ref()`, computed properties, auto-unwrapping

### Step 2: Todo List
**File**: `src/components/playground/TodoDemo.vue`
**Learn**: `v-for`, `v-model`, forms, events

### Step 3: Pinia Store
**File**: `src/components/playground/ThemeDemo.vue`
**Learn**: `defineStore()`, global state, localStorage

### Step 4: Interactive Playground
**File**: `src/components/playground/InteractivePlayground.vue`
**Learn**: All concepts together, `watch()`, real-time reactivity
